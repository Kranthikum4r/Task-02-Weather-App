# 🌦️ Live Weather Dashboard

A responsive weather dashboard that provides real-time weather information, hourly forecasts, a 5-day forecast, air quality data, and other weather metrics using the OpenWeatherMap API.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Current temperature and weather description
- 📅 Current date and time
- 🌅 Sunrise & Sunset timings
- 💧 Humidity
- 🌬️ Air Pressure
- 🤒 Feels Like temperature
- 👀 Visibility
- 🌫️ Air Quality Index (AQI)
- 🕒 Next 6 hourly forecasts
- 📆 5-day weather forecast
- 📱 Fully responsive UI
- 🎨 Glassmorphism design

## 🔑 API

This project uses the **OpenWeatherMap API**.

### Current Weather

```
https://api.openweathermap.org/data/2.5/weather
```

### Forecast

```
https://api.openweathermap.org/data/2.5/forecast
```

### Air Pollution

```
https://api.openweathermap.org/data/2.5/air_pollution
```

Get your API key from:

https://openweathermap.org/api
